■ 이번에 추가된 것
  1) 행사장 그림지도 (#map)
     - 바탕: 김지환 대표 일러스트 조감도(9/20, 존 이름 없는 판)
     - 존 이름표 10개 + 주차장·해녀박물관 표시, 누르면 설명 창
     - 체험존(1~12)·음식체험존(13~19): 9/18 부스 목록 + 김지환 대표 체험 예시 그림
     - 휴대폰에서는 지도를 옆으로 밀어서 볼 수 있음
  2) SNS 공유 (#share, 하단 '공유' 버튼)
     - 휴대폰: '공유하기' → 카카오톡·인스타그램·문자 등 기기 공유창
     - 페이스북 · X · 밴드 · 링크 복사 버튼
     - 인스타그램: 피드용(1080x1350)·스토리용(1080x1920) 그림 저장/바로 공유
     - 영상마다 '이 영상 공유하기' 버튼
     - '내 달력에 적어 두기'(구글 캘린더, 10/10 13:00~19:00)
     - 링크 미리보기 그림(og_card.jpg) — 카톡/페북에 주소를 붙이면 이 그림이 뜸

■ 선택 사항
  - 카카오톡 전용 '카카오 공유' 카드(버튼형)를 원하면 카카오 개발자 앱 키가 필요합니다
    (developers.kakao.com → 앱 만들기 → 사이트 도메인에 https://jejugrapher.github.io 등록 → JavaScript 키 전달).
